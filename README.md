# ⚡ Fast AI Image Generator

Generate images in ~40 seconds using GitHub Actions!

## 🚀 Quick Start
1. Go to **Actions** → **Generate AI Image**
2. Click **Run workflow**
3. Enter your prompt
4. Download image from Artifacts

## ⚡ Performance
- **First run**: ~2 minutes (downloads model)
- **Subsequent runs**: ~40-50 seconds (cached)

## 💡 Tips
- Use 4 steps for speed, 8 for quality
- Simple prompts work best
- Model: LCM Dreamshaper v7
